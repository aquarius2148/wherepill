WHEREPILL 사용설명서

WHEREPILL ver 1.2
약품 위치 검색 및 조제실 적응 훈련 프로그램

1. 엑셀 파일 준비하기
엑셀에서 약품명을 입력하고 바로 오른쪽 셀에 저장소 위치를 적으세요. 예시는 다음과 같습니다.

약품명       저장소     약품명       저장소
타이레놀     M1         아젤리아     L3
알마겔       S1         울트라셋     M4

• 반드시 A열부터 시작할 필요는 없습니다.
• 여러 시트의 약품 목록도 읽을 수 있습니다.
• 위치 코드는 M1, L3, S1, 12, 가1, 냉장고, ATC옆, 향정금고 등으로 입력하세요.
• 약품명과 위치 사이에 빈 셀을 넣지 마세요.
• 엑셀 파일(.xlsx 권장)을 바탕화면에 저장하세요.

2. 엑셀 파일 선택 / 갱신
① 메인 화면의 '엑셀 파일 선택 / 갱신' 버튼을 누릅니다.
② 파일 선택 창에서 바탕화면으로 이동합니다.
③ 약품 목록 엑셀 파일을 선택하고 '열기'를 누릅니다.
④ 등록된 약품 위치 수와 저장 완료 메시지를 확인합니다.
엑셀 내용을 수정한 경우 저장한 뒤 같은 버튼으로 다시 불러오세요. 정상적으로 읽히면 기존 검색 데이터가 새 목록으로 교체됩니다. 엑셀 원본은 수정되지 않습니다.

3. 약품명 검색
검색창에 약품명 전체 또는 일부를 입력하면 바로 오른쪽 셀에 있던 위치 코드가 표시됩니다. 대소문자와 띄어쓰기는 구분하지 않습니다. 여러 결과가 있으면 함께 표시되며, 결과가 많으면 '더 보기'를 누르세요.

4. 가상의 조제실
저장소 위치별로 약품을 묶어 가상 약장과 약통으로 보여줍니다. 약장은 숫자 → 알파벳 → 한글 순으로 정렬하며, 한 페이지에 최대 100개 약장을 표시합니다. 이전/다음 버튼으로 이동하세요. 위쪽 조제실 검색창에 약품명을 입력하면 해당 약장만 표시되고 일치하는 약통은 노란색으로 강조됩니다. 여러 약장이 일치하면 함께 표시합니다. 전체 보기로 원래 목록에 돌아갑니다. 약통 모양과 칸 안의 배열은 학습용이며 실제 모습이나 배치와 다를 수 있습니다.

5. 약찾기 퀴즈
등록된 약품을 무작위로 출제합니다. 30개 선택지 중 올바른 위치를 선택하세요. 정답은 초록색, 선택한 오답은 빨간색으로 표시됩니다. 실제 위치가 부족하면 가상의 오답 위치가 추가됩니다. 위치가 여러 곳인 동일 약품은 출제하지 않습니다. '다음 문제'로 계속하고 '퀴즈 다시 시작'으로 점수를 초기화할 수 있습니다.

6. 브라우저 저장 및 엑셀파일 비우기
정상적으로 불러온 약품 목록은 현재 브라우저에 저장되어, 다음 접속 시에도 다시 사용할 수 있습니다. 다른 PC나 브라우저에서는 파일을 별도로 선택해야 합니다.
'엑셀파일 비우기'를 누르고 확인하면 이 브라우저에 저장한 약품 목록과 현재 검색·퀴즈 데이터가 지워집니다. 실제 엑셀 파일은 삭제되지 않습니다. 브라우저 데이터 삭제, 시크릿 모드 등의 경우 저장 내용이 사라질 수 있습니다.

7. 메뉴 이동 및 참고사항
'메인 검색', '가상의 조제실', '약찾기 퀴즈' 메뉴를 통해 원하는 화면으로 이동하세요. 설명서는 '닫기' 또는 Esc 키로 닫을 수 있습니다.
엑셀 읽기 모듈을 불러오려면 인터넷 연결이 필요합니다. 선택한 엑셀은 브라우저 안에서 처리됩니다. 환자 개인정보가 포함되지 않은 약품 위치 목록만 사용하세요. 실제 조제 시에는 원본 목록과 약품명·함량을 반드시 확인하세요.
