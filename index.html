약품 위치 검색 및 조제실 적응 훈련 프로그램

1. 엑셀 파일 준비하기
엑셀에서 약품명을 입력하고 바로 오른쪽 셀에 저장소 위치를 적으세요. 예시는 다음과 같습니다.

약품명             저장소
칸데모어정16mg    A1
가상고양이시럽    냉장고
가상호랑이정      ATC옆

• 반드시 A열부터 시작할 필요는 없습니다. 보험코드 | 약품명 | 약위치 순서의 3열 양식도 사용할 수 있습니다.
  예: 000000001 | 타이레놀500mg | A1
• 같은 위치에 여러 약을 등록할 수 있습니다. 예를 들어 A1을 10행에 반복 입력하면 가상 조제실에서 하나의 A1 약장에 10개 약품이 표시됩니다.
• 여러 시트의 약품 목록도 읽을 수 있습니다.
• 위치 코드는 M1, L3, S1, 12, 가1, 냉장고, ATC옆, 향정금고 등으로 입력하세요.
• 약품명과 위치 사이에 빈 셀을 넣지 마세요.
• 엑셀 파일(.xlsx 권장)을 바탕화면에 저장하세요. 약품명 바로 오른쪽 칸에 A1, 냉장고, ATC옆처럼 원하는 보관 위치를 입력합니다. 보험코드는 선택 사항입니다.
• 팁: 약장 촬영 버튼으로 위치 표지와 약품명을 함께 촬영한 뒤 사진을 저장하고, AI에 사진을 넣어 약품명 | 약위치 형식의 엑셀 목록 제작을 요청할 수 있습니다. 사진만으로 정확한 함량이나 약품명이 판별되지 않을 수 있으므로 반드시 실제 포장과 대조하고 수정한 후 사용하세요. 환자 정보, 개인정보, 보안 정보가 있는 사진은 외부 AI에 올리지 마세요.

2. 엑셀 파일 선택 / 갱신
① 메인 화면의 '엑셀 파일 선택 / 갱신' 버튼을 누릅니다.
② 파일 선택 창에서 바탕화면으로 이동합니다.
③ 약품 목록 엑셀 파일을 선택하고 '열기'를 누릅니다.
④ 등록된 약품 위치 수와 저장 완료 메시지를 확인합니다.
엑셀 내용을 수정한 경우 저장한 뒤 같은 버튼으로 다시 불러오세요. 정상적으로 읽히면 기존 검색 데이터가 새 목록으로 교체됩니다. 엑셀 원본은 수정되지 않습니다.
• 실제 목록이 없을 때는 내장 테스트 약품 100개가 자동으로 표시됩니다. 모든 이름에는 (테스트)가 붙고 실제 약품과 섞이지 않습니다. 테스트 엑셀도 내려받을 수 있습니다.

3. 약품명 검색
검색창에 약품명 전체 또는 일부를 입력하면 바로 오른쪽 셀에 있던 위치 코드가 표시됩니다. 대소문자와 띄어쓰기는 구분하지 않습니다. 여러 결과가 있으면 함께 표시되며, 결과가 많으면 '더 보기'를 누르세요.

4. 가상의 조제실
저장소 위치별로 약품을 묶어 가상 약장과 약통으로 보여줍니다. 약장은 숫자 → 알파벳 → 한글 순으로 정렬하며, 한 페이지에 최대 100개 약장을 표시합니다. 이전/다음 버튼으로 이동하세요. 위쪽 조제실 검색창에서는 약품명 또는 약장 위치를 검색할 수 있습니다.
• 약품명 검색: 예를 들어 '국장님눈치차단연고'를 입력하면 해당 약이 있는 약장 전체를 보여주고 일치하는 약통을 노란색으로 강조합니다.
• 위치 검색: 'A1', 'M4', '가1', '냉장고', 'ATC옆', '향정금고' 등을 입력하면 해당 약장의 모든 약품을 보여줍니다. 정확히 일치하는 위치가 있으면 우선 표시합니다(A1 입력 시 A10 제외).
• 정확한 위치가 없으면 약품명이나 위치의 일부가 일치하는 약장을 함께 표시합니다(예: M → M1, M2 등; 금고 → 향정금고). 대소문자와 띄어쓰기는 구분하지 않습니다.
• '전체 보기'로 검색을 해제하고 전체 약장으로 돌아갑니다. 약통 모양과 칸 안의 배열은 학습용이며 실제 모습이나 배치와 다를 수 있습니다.

5. 약찾기 퀴즈
등록된 약품을 무작위로 출제합니다. 30개 선택지 중 올바른 위치를 선택하세요. 정답은 초록색, 선택한 오답은 빨간색으로 표시됩니다. 실제 위치가 부족하면 가상의 오답 위치가 추가됩니다. 위치가 여러 곳인 동일 약품은 출제하지 않습니다. '다음 문제'로 계속하고 '퀴즈 다시 시작'으로 점수를 초기화할 수 있습니다.

6. 브라우저 저장 및 엑셀파일 비우기
정상적으로 불러온 약품 목록은 현재 브라우저에 저장되어, 다음 접속 시에도 다시 사용할 수 있습니다. 다른 PC나 브라우저에서는 파일을 별도로 선택해야 합니다. 이전에 불러온 목록은 자동 갱신되지 않으므로 엑셀 원본을 바꾸면 다시 갱신하세요.
'엑셀파일 비우기'를 누르고 확인하면 현재 선택된 약국의 약품 목록, 약장 사진, 최근 검색 및 오답 기록만 지워지고 내장 테스트 목록이 표시됩니다. 다른 약국은 그대로 유지됩니다. 실제 엑셀 파일은 삭제되지 않습니다. 브라우저 데이터 삭제, 시크릿 모드 등의 경우 저장 내용이 사라질 수 있습니다.

7. 메뉴 이동 및 참고사항
'메인 검색', '가상의 조제실', '약찾기 퀴즈' 메뉴를 통해 원하는 화면으로 이동하세요. 설명서는 '닫기' 또는 Esc 키로 닫을 수 있습니다.
8. 검색 및 학습 기능
• 메인 검색은 한글 초성(ㅇㅁㅈㅌ 등)과 오타 추정 후보를 지원합니다. 오타 후보는 정답이 아니므로 반드시 이름과 함량을 확인하세요. 최근 검색어를 눌러 다시 검색하거나 약장 보기로 이동할 수 있습니다.
• 노란색 메인 검색 버튼으로 돌아갑니다. 가상 조제실에서 마약이 들어간 위치명은 열린 3단 금고, 향정·금고도 별도의 3단 금고, 냉장고는 냉장 쇼케이스로 표시합니다. 보관 장소 선택에서 각 종류만 따로 볼 수 있습니다. 전체 보기로 검색 및 분류를 초기화합니다. 시럽·현탁액·액 등으로 끝나는 약품명(뒤에 함량/용량이 있어도 적용)은 시럽병 3종으로 표시하며 연고·크림으로 끝나는 약품명(함량·용량 포함)은 공통 연고/크림 튜브 3종으로 표시합니다. 다른 약품은 약통 10종과 종이약상자 3종을 섞습니다. 모든 약품 용기 PNG는 투명 배경입니다. 실제 포장 및 보관조건을 뜻하지 않습니다.
• 실제 사진 등록: 각 약장에서 갤러리 사진을 선택하거나 바로 옆 약장 촬영 버튼으로 찍으면 해당 위치에 자동 등록됩니다. 사진 보기·삭제·파일 저장이 가능합니다. 테스트 모드의 사진은 실제 목록 사진과 분리됩니다. 엑셀 백업에는 사진이 포함되지 않습니다.
• 퀴즈의 학습 범위 및 약장 선택을 바꾸면 해당 범위에서 출제합니다. 오답노트는 틀린 횟수를 저장하며 오답 집중 암기는 틀린 약품을 반복 출제합니다.
• 약품 목록 관리에서 추가·수정·삭제하고 엑셀 백업으로 보험코드·약품명·약위치를 내보냅니다. 변경은 브라우저 목록에만 반영되며 원본에는 적용되지 않습니다. 원본을 갱신하면 브라우저 목록을 대체합니다.
• 엑셀파일 비우기는 현재 선택한 약국의 저장 목록, 실제 약장 사진, 최근 검색어와 오답노트만 제거하고 테스트 모드로 돌아갑니다. 테스트 모드에서 실제 약품 목록을 수정하려면 먼저 엑셀을 불러오세요.
9. 약장 촬영 및 사진 저장
가상의 조제실에서 해당 약장의 실제 사진 등록 옆에 있는 약장 촬영을 누르세요. 스마트폰 카메라로 찍고 확인하면 해당 위치에 사진이 자동 등록되며 바로 표시됩니다. PC에서는 파일 선택창이 열릴 수 있습니다. 같은 위치에 새 사진을 등록하면 기존 사진을 교체합니다. 사진 저장 버튼으로 등록된 사진 파일을 내려받을 수 있습니다. 브라우저 저장은 갤러리 자동 저장과 다르며 기기 간 자동 공유되지 않습니다. 환자정보가 담긴 처방전 등은 촬영하지 마세요. 이 기능은 OCR이 아니며 사진을 서버로 보내지 않습니다. 새 사진은 긴 변 최대 1280픽셀, JPEG 품질 65% 이하로 자동 압축하여 장당 200KB 이하를 목표로 저장합니다. 실제 용량은 사진마다 다르며 기존 사진은 손실을 막기 위해 그대로 유지합니다.
냉장고 안의 가상 약품은 모두 동일한 흰색·보라색 종이곽으로 표시됩니다. 실제 포장이나 냉장 보관 여부를 판단하는 정보가 아닙니다.
10. 기타 안내
탕비실 및 장식 소품은 실제 약품 위치나 퀴즈 데이터에 포함되지 않습니다.


11. 약국별 저장 및 ZIP 공유
• 화면 위쪽 ‘현재 약국’에서 약국을 바꾸면 약품 목록, 실제 사진, 최근 검색 및 오답노트가 함께 전환됩니다. 마지막으로 선택한 약국이 다음 실행 때 복원됩니다.
• ‘약국 관리 · ZIP 공유’ → 새 약국 등록 → 이름 입력 → 닫기 → 엑셀 선택 / 갱신. 이름 변경, 복제, 삭제도 이 메뉴에서 할 수 있습니다. 다른 약국과 원본 엑셀에는 영향을 주지 않습니다.
• 이전 버전에서 저장한 데이터는 최초 실행 시 ‘기존 약국’으로 옮겨집니다. 실제 약국 이름으로 변경할 수 있습니다.
• ‘선택 약국 ZIP 준비’ 또는 ‘전체 약국 ZIP 준비’를 눌러 백업 파일을 생성합니다. 약품목록.xlsx, 약국정보.json과 위치별 사진 파일이 들어갑니다. 개인 학습 기록은 기본적으로 제외하며 체크하면 포함됩니다. 비어 있는 약국은 내장 테스트 목록으로 백업됩니다.
• 준비된 ZIP의 용량을 확인하고 ‘ZIP 다운로드’ 또는 ‘카카오톡 등 공유’를 선택하세요. 공유 메뉴 미지원 기기에서는 다운로드 후 카카오톡에서 파일을 첨부하세요. 250MB 초과 시 경고하며 이 버전에서 한 번에 처리할 수 있는 ZIP은 350MB 이하입니다. 여러 약국은 약국별로 나누어 공유하는 것을 권장합니다.
• 새 컴퓨터에서 같은 홈페이지를 열고 ‘약국 ZIP 불러오기’로 받은 ZIP 자체를 선택하세요. 압축 해제는 필요 없습니다. 같은 약국 이름이 있으면 기본적으로 별도 등록하며, 기존 약국 교체를 선택하면 확인 후 덮어씁니다. ZIP 안의 엑셀과 위치 연결 정보가 일치해야 복원됩니다.
• 사진은 새로 등록할 때 자동 저용량 JPEG로 변환합니다. 기존 사진은 보존됩니다. 위치별 사진은 기기와 브라우저별로 저장되며 실시간 동기화되지 않습니다. 브라우저 삭제 또는 저장 공간 정리 전에 ZIP 백업을 권장합니다. 여러 탭에서 동시에 데이터를 편집하지 마세요.
• ZIP에는 암호가 설정되지 않습니다. 공유할 때는 약국 동의를 받고 환자 정보, 처방전, 보안 정보가 담긴 사진이 없는지 확인하세요. 받은 약국 목록의 실제 약품명과 위치는 반드시 확인한 후 사용하세요.

엑셀 읽기 모듈을 불러오려면 인터넷 연결이 필요합니다. 선택한 엑셀은 브라우저 안에서 처리됩니다. 환자 개인정보가 포함되지 않은 약품 위치 목록만 사용하세요. 실제 조제 시에는 원본 목록과 약품명·함량을 반드시 확인하세요.
